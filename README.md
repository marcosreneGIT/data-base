# **Curso de Banco de Dados: do Básico ao Avançado**

## **Conteúdo do Curso**

Este curso oferece um aprendizado completo e prático sobre bancos de dados relacionais e não relacionais, abrangendo desde os conceitos básicos até tópicos avançados.

* **Bancos de Dados Relacionais**: MySQL, PostgreSQL e SQLite
* **Bancos de Dados Não Relacionais**: MongoDB, CouchDB, Redis e Firebase
* **Modelagem de Dados**: Criação e estruturação de bancos de dados relacionais
* **Normalização**: Aplicação das formas normais para validação dos modelos
* **SQL**: Sintaxe, consultas, operadores lógicos e funções
* **CRUD**: Criação, consulta, atualização e exclusão de dados
* **SGBDs**: Instalação e configuração de diferentes sistemas de gerenciamento de bancos de dados
* **Aplicações Práticas**: Desenvolvimento de 14 aplicações CRUD utilizando Python, Java e os bancos de dados estudados
