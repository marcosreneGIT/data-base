# **Curso de Banco de Dados: do Básico ao Avançado**

[svg](https://github.com/marcosreneGIT/database)

## **Conteúdo do Curso**

[svg](https://github.com/marcosreneGIT/database#conte%C3%BAdo-do-curso)

Este curso oferece um aprendizado completo e prático sobre bancos de dados relacionais e não relacionais, abrangendo conceitos fundamentais, modelagem de dados, SQL e utilização de diferentes Sistemas Gerenciadores de Banco de Dados.

* **Bancos de Dados**: Conceitos fundamentais sobre bancos de dados relacionais e não relacionais
* **Modelagem de Dados**: Criação e estruturação de bancos de dados relacionais
* **Normalização**: Aplicação das formas normais para validação e organização dos modelos
* **SQL**: Sintaxe, consultas, operadores lógicos, funções e manipulação de dados
* **Funções Agregadas**: Análise e agrupamento de dados utilizando funções SQL
* **Bancos de Dados Relacionais**: Utilização de MySQL, PostgreSQL e SQLite
* **Bancos de Dados Não Relacionais**: Utilização de MongoDB, CouchDB, Redis e Firebase
* **CRUD**: Criação de aplicações utilizando operações de Create, Retrieve, Update e Delete
* **Aplicações Práticas**: Desenvolvimento de 14 aplicações CRUD utilizando Python, Java e os bancos de dados estudados
* **SGBDs**: Instalação e configuração de diferentes Sistemas Gerenciadores de Banco de Dados
* **SQL x NoSQL**: Compreensão das diferenças e aplicações de bancos relacionais e não relacionais

## **Objetivos**

Ao concluir o curso, será possível:

* Instalar e utilizar diferentes Sistemas Gerenciadores de Banco de Dados
* Trabalhar com bancos de dados relacionais e não relacionais
* Modelar bancos de dados relacionais aplicando as formas normais
* Desenvolver consultas SQL simples e complexas
* Diferenciar e utilizar bancos de dados SQL e NoSQL
* Desenvolver aplicações CRUD utilizando diferentes linguagens e bancos de dados
